
# Sunday School Platform

A web-based platform designed to help Sunday School teachers organize and manage their service activities.

## About the Project

The platform provides an organized interface for managing teachers, children, classes, attendance, lessons, lesson preparation, activities, tasks, birthdays, and reports.

It is designed for Sunday School services, from nursery through sixth grade of primary school.

## Features

* Login and registration interface
* Dashboard
* Teachers management
* Children management
* Classes management
* Attendance tracking
* Lessons library
* Lesson preparation
* Activities and tasks
* Birthdays and reports
* Settings and profile pages

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Git and GitHub
* GitHub Pages

## Project Status

This project is currently in frontend development. Some features use browser Local Storage for demonstration purposes. Backend integration and a real database have not yet been implemented.
